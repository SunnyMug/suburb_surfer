# Suburb Surfer

A full-stack Next.js application that lets you explore suburbs across Australian capital cities. Pick a random suburb or search for one by name, then browse an overview, food scene, and local history — all surfaced on an interactive map.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Groq Cloud (LLaMA 3.3 70B with LLaMA 3.1 8B as fallback)
- Google Maps embed

## Getting Started

1. Clone the repo and install dependencies:

```bash
npm install
```

2. Create a `.env.local` file in the project root and add your Groq API key:

```
GROQ_API_KEY=your_key_here
```

You can get a free API key at [console.groq.com](https://console.groq.com).

3. Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Random suburb discovery or manual search
- Supports all Australian capital cities
- Overview, food scene, and history tabs
- Load more restaurant recommendations on demand
- Model fallback and timeout handling for API reliability

## AI Use Disclaimer

Suburb information displayed in this application is generated by a large language model (LLaMA 3.3 via Groq). While prompts are designed to reduce inaccuracies, AI-generated content can still be incorrect, outdated, or incomplete. Restaurant recommendations in particular should be verified before visiting. Do not rely on this application for time-sensitive or safety-critical decisions.
